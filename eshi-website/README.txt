ESHI WEBSITE — FIRST WORKING VERSION

1. Extract this folder.
2. Open index.html in Chrome to preview it.
3. Add the song:
   Put an MP3 file in assets/music/ and name it exactly:
   favorite-song.mp3
4. Customize the story:
   Open index.html and replace the placeholder paragraphs inside #full-story-text.
5. Customize memories:
   Open js/main.js and edit the memories object. Then edit the three memory-card titles/descriptions in index.html.
6. Preview again by refreshing index.html.

Notes:
- Music may not autoplay until the first interaction. The turkey catch is the first interaction and attempts to start it.
- Use a song file you have permission to use. For a public website, consider linking to the song instead of distributing the audio file.
- This is a starter prototype. Test it on both desktop and a phone before sharing.
- To publish with GitHub Pages: create a GitHub repository, upload the contents of this folder, then enable Pages in the repository's Settings > Pages.
